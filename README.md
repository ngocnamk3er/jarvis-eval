# jarvis-eval

Black-box **benchmark** harness for the Jarvis agent. Runs standard public
benchmarks against the deployed test cluster and reports the standard
metrics next to published SOTA.

| suite | dataset (HuggingFace) | what it measures | reference |
|---|---|---|---|
| `beir_scifact` | `BeIR/scifact` (5.2k docs, 300 queries) | retrieval — nDCG@10, recall@{10,100}, MRR@10 | text-embedding-3-large nDCG@10 ≈ 0.78 |
| `beir_nfcorpus` | `BeIR/nfcorpus` (3.6k docs, 323 queries) | same | text-embedding-3-large nDCG@10 ≈ 0.42 |
| `hotpotqa` | `hotpotqa/hotpot_qa` distractor dev (sampled) | multi-hop — supporting-fact recall@{2,5} + answer EM/F1 | strong RAG answer F1 ≈ 0.6–0.8 |
| `gaia` | `gaia-benchmark/GAIA` validation L1 | agent tasks — exact-match score | SOTA overall ≈ 0.5–0.7 |

Each benchmark's corpus is uploaded into its own isolated `eval-<name>`
Keycloak file workspace (file-service vector search has no path filter) and
embedded with `openai/text-embedding-3-large` @1024 dims, exactly like a file
a user would upload.

## Scores

Full scoreboard: **[`RESULTS.md`](RESULTS.md)** (committed, regenerated by
`jeval baseline`). Machine-readable: `datasets/baseline.json`.

| | measured | reference |
|---|---|---|
| SciFact nDCG@10 | **0.769** | ~0.78 |
| NFCorpus nDCG@10 | **0.410** | ~0.42 |
| HotpotQA support_recall@5 | **0.887** | strong |
| HotpotQA both@5 (both supporting paras in top 5) | **0.777** | strong |
| HotpotQA answer F1 (47/50 Qs, 3 agent timeouts) | **0.753** | 0.6–0.8 |

Verdict: on standard benchmarks Jarvis's retrieval + RAG sits at published
`text-embedding-3-large` level (was bge-m3-dense until 2026-09-07). The
NFCorpus gap is chunking splitting longer docs across chunks and diluting
their ranking — real signal for RAG work. A reranker closes most of it
(`jeval rerankcompare`): SciFact +0.04 nDCG@10, HotpotQA both@5 0.78 → 0.91.

`jeval baseline --show` prints the `RESULTS.md` scoreboard without needing a run.

## Quick start

```bash
make install
cp .env.example .env          # fill INTERNAL_API_KEY (+ HF_TOKEN only for gaia)
jeval setup                   # create the eval + eval-<benchmark> users
make port-forward             # kubectl port-forward svc/file-service 18002:8000

# one-off, ~40 min total (download + upload + embed each corpus)
jeval seed beir_scifact
jeval seed beir_nfcorpus
jeval seed hotpotqa

# score one benchmark
jeval run --suite beir_scifact               # near-free, ~5 min
jeval run --suite beir_nfcorpus              # near-free, ~5 min
jeval run --suite hotpotqa                   # retrieval free; ~50 agent Qs ≈ $1–3
jeval run --suite gaia                       # needs HF_TOKEN

# several into one report, or everything
jeval run --suite beir_scifact,beir_nfcorpus
jeval run --suite all

jeval report --baseline --fail-on-regression # print + gate the newest run
jeval baseline                               # freeze it as the new bar (updates RESULTS.md)
jeval baseline --show                        # just print the current scoreboard

make stop-port-forward
```

`results/<timestamp>/{report.md, results.json, raw.json}` is written per run
and kept (git-ignored). `report.md` shows only the suites in that run, with
deltas vs `datasets/baseline.json`.

## Offline experiments (no cluster)

Try a change before touching file-service. These embed the cached BEIR /
HotpotQA corpora themselves and score locally — no `make port-forward`, no
`jeval seed`. They need an OpenRouter key in `.env`
(`EMBEDDING_API_KEY` for embeddings, `OPENROUTER_API_KEY` for chat) and print
a live `$` total.

```bash
# candidate embedding model vs the committed baseline (BEIR)
jeval embcompare openai/text-embedding-3-large --dims 1024

# what a reranker adds — dense vs reranked, on beir_* + hotpotqa
jeval rerankcompare google/gemini-2.5-flash                     # listwise LLM (RankGPT), default
jeval rerankcompare cross-encoder/ms-marco-MiniLM-L-6-v2 --backend local
#   local backend needs:  pip install -r requirements-rerank.txt \
#                             --extra-index-url https://download.pytorch.org/whl/cpu

# sentence-level Sup EM / F1 for HotpotQA (the leaderboard metric) via an
# LLM supporting-fact selector — distractor / dense / rerank contexts
jeval hotpotsup google/gemini-2.5-flash --context all
```

Cluster secrets for `.env`:

```bash
kubectl -n jarvis get secret jarvis-secrets \
  -o jsonpath='{.data.INTERNAL_API_KEY}' | base64 -d ; echo
kubectl -n jarvis get secret jarvis-keycloak-secrets \
  -o jsonpath='{.data.KC_BOOTSTRAP_ADMIN_PASSWORD}' | base64 -d ; echo
```

## GAIA

Gated dataset — set `HF_TOKEN` in `.env` and accept the terms once at
https://huggingface.co/datasets/gaia-benchmark/GAIA . Jarvis can't open
GAIA's file attachments, so only no-attachment level-1 questions run; expect
a low score (it partly measures "Jarvis is not a browsing agent").

## Regression gate

`jeval report --baseline --fail-on-regression` exits non-zero if, vs
`datasets/baseline.json`:

- `beir_scifact` / `beir_nfcorpus` nDCG@10 drops > 0.03
- `hotpotqa` support_recall@5 or answer F1 drops > 0.05

After a real improvement, re-run and `jeval baseline` to raise the bar.

## Cost / determinism

BEIR is pure retrieval — only query embeddings, near-free. HotpotQA runs the
agent over `BENCH_AGENT_SAMPLE` (default 50) questions (~$1–3). The backend
runs at `temperature=0`; benchmark samples are fixed-seed (42) so re-runs
compare like-for-like. HF datasets are cached under `~/.cache/jarvis-eval/`.

## Jenkins job

Nightly-cron + manual (not on push). Assumes corpora are already seeded;
the job just re-scores BEIR + gates on regression.

1. **New Item → Pipeline**, name `jarvis-eval`.
2. **Pipeline script from SCM**, Git `http://gitlab:8929/root/jarvis-eval.git`,
   branch `main`, Script Path `Jenkinsfile`.
3. Add a **Secret file** credential id `jarvis-eval-env` = a filled `.env`
   (`INTERNAL_API_KEY`, `KC_ADMIN_PASSWORD`, `HF_TOKEN`; `INGRESS_IP` if not
   `192.168.49.2`).
4. The agent needs `kubectl` with a kubeconfig that can reach the `jarvis`
   namespace (for the port-forward).

## Layout

```
jarvis_eval/
  config.py            settings (.env)
  metrics.py           IR primitives + SQuAD/HotpotQA EM/F1 + aggregate helpers
  trace.py             RunTrace — one agent run's tools / tokens / $ / latency
  report.py            aggregate -> results.json + report.md, baseline diff, gate
  cli.py               `jeval`
  embcompare.py        offline: score a candidate embedding model on BEIR
  rerankcompare.py     offline: dense vs + reranker (LLM listwise / CPU cross-encoder)
  hotpotsup.py         offline: sentence-level Sup EM/F1 via an LLM selector
  clients/
    auth.py            per-user Keycloak token + Admin-API user creation
    conversations.py   create / delete / messages / sandbox-file
    chat.py            SSE driver: run_agent(prompt) -> RunTrace  (hotpotqa/gaia)
    files.py           bulk upload + vector/grep search, file-service direct
  benchmarks/
    hf.py              HF parquet loader (no `datasets` lib), cached
    beir.py            SciFact / NFCorpus
    hotpotqa.py        distractor multi-hop
    gaia.py            validation L1 no-attachment subset
datasets/baseline.json    results/   Makefile   Jenkinsfile
```
